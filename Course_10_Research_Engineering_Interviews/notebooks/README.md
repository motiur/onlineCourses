# Course 10 notebooks: Research Engineering Interviews

One notebook per session. Open them in Kaggle Notebooks or Google Colab.

- Each notebook gives the problems as stubs with tests. Work them under a timer first.
- The "Reference solutions" section at the bottom of a notebook defines working versions and runs the same tests. Remove that section before giving a notebook to students if you want to keep the answers back.
- All tests and reference solutions were run once on a CPU on 17 November 2026 with Python 3, NumPy 2.5, SciPy 1.18, pandas and PyTorch 2.15.
