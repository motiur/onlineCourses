# Course 13 notebooks: Deep Learning on Curved Spaces

One notebook per session. Read them with their saved outputs on the course website or on GitHub, or open them in Google Colab or Kaggle Notebooks and run them from the top.

- Every cell without a NOT RUN label was run once, top to bottom, on a CPU in November 2026 (Python 3.13, NumPy 2.5, SciPy 1.18, scikit-learn 1.9, networkx 3.7 and matplotlib 3.11, plus PyTorch 2.15 in sessions 5–8 and 10–12), and the outputs are saved in the notebooks. A second, independent run reproduced every printed number; only timings differ.
- The geometry is implemented by hand in NumPy and PyTorch (exponential and logarithm maps, Möbius operations, Riemannian gradients, SPD means, rotation maps), and every formula is checked numerically in the notebook: round trips, identities, and comparisons with SciPy. The data are synthetic (trees, directions on the sphere, EEG-like covariance matrices, rotated point clouds) or generated by networkx, so each notebook finishes in under a minute on a CPU.
- Cells marked TODO are exercises for students. Cells marked NOT RUN show the same steps with libraries that are not installed here (geoopt, geomstats, pyRiemann, nltk's WordNet, MOABB); they were written from the libraries' documented interfaces and have not been executed, so run each one before recording (the table below says what each needs).
- Nothing extra needs installing for the runnable cells on Google Colab or Kaggle.
- Results that went against expectation are stated in each notebook's "What to notice" cell and in the course document. Examples: Sarkar's tree embedding with short edges did worse than a flat layout, because branches overlapped (session 4); in 10 dimensions a Euclidean embedding of the tree matched or beat the hyperbolic one, while in 2 dimensions the hyperbolic one always won (session 7); a Euclidean MLP beat the hyperbolic MLP at every size we tried (session 8); after recentring each subject's data, all four SPD classifiers, Euclidean included, reached about the same accuracy (session 9); Riemannian flow matching matched the data much better than Euclidean flow matching but leaked more mass between clusters (session 11); in the mixed-curvature embeddings the sphere factor became almost flat and the circle factor collapsed in two of three runs (session 12).
