# Course 15 notebooks: Machine Learning for Agriculture and Climate

One notebook per session. Read them with their saved outputs on the course website or on GitHub, or open them in Google Colab or Kaggle Notebooks and run them from the top.

- Every cell without a NOT RUN label was run once, top to bottom, on a CPU in November 2026 (Python 3.13, NumPy 2.5, SciPy 1.18, pandas 3.0, scikit-learn 1.9 and matplotlib 3.11, plus PyTorch 2.15 in sessions 2, 4 and 7–9), and the outputs are saved in the notebooks. A second, independent run reproduced every printed number; only timings differ.
- All lab data are synthetic, generated in the notebooks to behave like the real thing: multispectral image time series with clouds, crop-phenology curves, district yield panels, weather series, a Lorenz-96 "atmosphere", radar images with speckle, climate-model output and farm sensor streams. Each notebook says which real dataset its data stand in for, and a NOT RUN cell shows how to load that dataset (ERA5 from the Copernicus Climate Data Store, Sentinel-1 and Sentinel-2 from public STAC catalogues, PlantVillage, Sen1Floods11, WeatherBench 2, CMIP6). Synthetic data make the numbers illustrations, not findings about Bangladesh.
- Cells marked TODO are exercises for students. NOT RUN cells need a download, an account or a library that is not installed here (the table below says what each needs). They were written from the libraries' documented interfaces and have not been executed, so run each one before recording.
- Nothing extra needs installing for the runnable cells on Google Colab or Kaggle.
- Results that went against expectation are stated in each notebook's "What to notice" cell and in the course document. Examples: a leaf mask did worse than randomizing the background (session 2); smoothing did not improve green-up dates (session 3); even the linear model's 90% prediction intervals covered only 88% of the yields in held-out years (session 5); the rain-probability forecast had little skill (session 6); a model trained to forecast five days directly was worse than rolling out a one-step model until day 10 (session 7); a fixed radar threshold beat Otsu's method, and the CNN fell below Otsu on darker scenes (session 8); quantile delta mapping kept the change in heavy rain but not in the mean (session 9); deciding from a Kalman filter without drift correction caused the most crop-stress days (session 11).
